# Windermere · landingspagina

Landingspagina voor Windermere, een fictief merk van stevige ontbijtthee (schoolopdracht Creative Automation, Robbe De Keyser).

- **Live:** https://robbedekeyser2-create.github.io/windermere/
- **Inschrijven:** ingebed MailerLite-formulier (voornaam, e-mail, opt-in), met double opt-in.
- **Bestanden:** `index.html` (pagina), `privacy.html` (privacyverklaring), `css/style.css` (huisstijl), `img/` (Firefly-beelden en logo), `video/` (Firefly-video).

De pagina is gebouwd met Claude Code ("vibe coding") op basis van de goedgekeurde copy. Beelden en video zijn gemaakt met Adobe Firefly.
